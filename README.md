# vai-app

**车载监控平台app**

**系统版本号**
V4.1.0

**系统介绍**
  车载监控APP管理终端设备，能查看设备信息，配置全局配置，NVR配置，高精度定位信息，webrtc信息，终端信息。完成设备注册、注销、恢复出厂、重启等功能。
  

## 系统功能
1. 设备信息
   查看设备IMEI、IMSI、MAC地址、CPUID，以及各软件版本号和启动状态
2. 全局配置
   a、配置消息总线地址，完成设备和服务器之间的通信设置，即rabbitmq的配置
   b、配置升级服务地址，完成设备升级服务地址信息设置
   c、配置心跳服务地址，完成心跳信息上报设置
   d、配置设备4G模组信息
   e、配置其他通用设置
   f、配置设备应用各软件的开发，控制应用软件的开启与关闭功能
3. NVR配置
   a、完成视频存储基本配置
   b、完成摄像头列表基本信息配置
   c、配置内部消息总线
4. 高精度定位
   a、配置GPS参数信息
   b、配置差分服务器信息
5、WEBRTC推流配置
   a、配置推流服务器基本配置
   b、配置webRtc摄像头推流列表
6、终端信息
   a、输入车牌号，制造商ID、车牌颜色、联系方式、型号等功能，完成终端设备注册和注销功能
7、恢复出厂设置
   a、将设备恢复到最原始状态
8、设备重启
   a、命令控制设备重启
